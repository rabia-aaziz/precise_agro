# AgriCare Editable Agriculture Website

## Pages included
- `index.html` — Home
- `pages/products.html` — Agriculture Products
- `pages/problem.html` — Crop Problem Solver
- `pages/photo.html` — Crop Photo Upload
- `pages/tips.html` — Farming Tips
- `pages/contact.html` — Contact / WhatsApp
- `pages/about.html` — About AgriCare
- `pages/login.html` — Login UI
- `pages/register.html` — Registration UI
- `pages/cart.html` — Cart UI
- `pages/checkout.html` — Checkout UI

## Edit in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Run `index.html` with Live Server.
4. Change text/products/prices in the HTML files.
5. Change colors/layout in `css/style.css`.
6. Change languages and voice settings in `js/main.js`.
7. Replace the demo phone/WhatsApp number with your real number.

## Important
The login, registration, cart, checkout and crop diagnosis are currently frontend/demo pages. They are ready to be connected to PHP/MySQL, Node.js or another backend later.

The design is intended for both educated and less-educated users: large buttons, icons, simple wording, Urdu + English, multiple regional-language options, voice reading, and photo-based help.
